# E-Commerce Data Analytics Project

## Project Overview

This project is an end-to-end E-Commerce Sales Data Analytics project developed using Python, SQL, and Power BI. The project focuses on analyzing sales performance, customer behavior, product performance, and regional sales trends to generate meaningful business insights.

---

## Objectives

* Perform data cleaning and preprocessing
* Analyze sales and profit trends
* Identify top-performing regions, categories, and customers
* Create interactive dashboards for business insights
* Practice end-to-end data analytics workflow

---

## Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* MySQL
* MySQL Workbench
* Power BI

---

## Project Workflow

### 1. Data Collection

* Imported Superstore sales dataset in CSV format

### 2. Data Cleaning

* Checked missing values
* Removed duplicate records
* Converted date columns into proper format

### 3. Exploratory Data Analysis (EDA)

Performed analysis on:

* Regional sales performance
* Category-wise sales
* Monthly sales trends
* Customer purchasing behavior
* Profit analysis

### 4. SQL Analysis

Executed SQL queries for:

* Total sales analysis
* Top customers
* Profit by category
* Region-wise analysis
* Monthly trends

### 5. Power BI Dashboard

Created interactive dashboard with:

* KPI Cards
* Sales by Region Chart
* Category-wise Pie Chart
* Monthly Sales Trend
* Interactive Filters/Slicers

---

## Key Insights

* West region generated the highest sales.
* Technology category contributed significant revenue.
* Some products generated negative profit.
* Monthly sales trends showed seasonal variations.
* High discounts affected profitability.
